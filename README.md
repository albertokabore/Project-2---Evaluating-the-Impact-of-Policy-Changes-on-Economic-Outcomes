# Project 2 — Evaluating the Impact of Policy Changes on Economic Outcomes

Counterfactual analysis of the Federal Reserve's 2022 monetary tightening cycle: what
would U.S. inflation and output have looked like had the Fed **not** raised interest
rates starting March 2022?

## Method

A regression-based structural time-series counterfactual (intervention analysis / a
CausalImpact-style local-level model with control covariates), fit on pre-intervention
data only and projected forward through the post-intervention window to build the
"no policy change" counterfactual. See `report/Policy_Impact_Counterfactual_Analysis_Report.docx`
for the full write-up (methodology, results, limitations, conclusions).

## Project structure

```
data/raw/            Cached raw pulls from FRED (one CSV per series)
data/processed/      (reserved for any exported processed datasets)
src/
  data_collection.py     Fetches series from FRED (pandas-datareader, no API key needed)
  preprocessing.py       Cleans, transforms (YoY %), and splits data by intervention date
  counterfactual_model.py  Fits the structural time-series counterfactual model
  visualization.py        Shared plotting helpers
notebooks/
  01_policy_impact_analysis.ipynb   End-to-end analysis notebook (run top to bottom)
report/
  Policy_Impact_Counterfactual_Analysis_Report.docx/.pdf   Submission-ready report
  figures/            PNG figures generated by the notebook, embedded in the report
  stats.json          Numeric results extracted for the report tables
```

## Setup

```
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
jupyter notebook notebooks/01_policy_impact_analysis.ipynb
```

All data is fetched live from [FRED](https://fred.stlouisfed.org/) on first run; no API
key or manual download is required. Re-running the notebook end to end reproduces every
number and figure in the report.
